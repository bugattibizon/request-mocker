Response Headers
Every page request returns the same items from your response body.
The total count is inflated so the UI renders real pagination controls.
How it works
The interceptor reads the page number from ?page=N in the URL, then updates every pagination field it finds in the response: current_page, total_pages, total_count, prev_page, next_page, first_page?, last_page?, offset_value.
Leave path empty to auto-detect the pagination object. Items array is returned unchanged on every page.
